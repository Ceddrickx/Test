About This Website

BUSPROS Exam Hub is a static reviewer launcher for weekly SAP S/4HANA practice exams. Each week opens in its own page, so question banks and saved attempts remain separate.

Progress is stored locally in your browser. Publishing this on GitHub Pages will still work as long as the exam HTML files and assets folder stay beside this index page.
